# Panda Auto Detailing

Strona studia auto detailingu z Torunia: powłoki ceramiczne, folie PPF, polerowanie i czyszczenie aut. Projekt i wykonanie dla klienta, strona działa produkcyjnie.

Strona: https://pandadetailing.pl

## Co jest w środku

- strona główna z animacjami GSAP i ScrollTrigger (przyciski magnetyczne, sekcja procesu, płynne przewijanie)
- pięć podstron usług pod lokalne SEO, cennik, polityka prywatności, strona 404
- galeria z lightboxem, plakietka z oceną Google, menu kontaktowe
- dane strukturalne, Open Graph, sitemap i robots.txt
- zdjęcia w WebP i lekki kod bez frameworka

## Technologie

HTML, CSS, JavaScript, GSAP. Hosting na Vercel.
